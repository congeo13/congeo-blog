<p>Η <a href="http://www.congeo.gr/tag/google">Google</a> ανακοίνωσε <a href="http://congeo.gr/google-project-glass/">τα φουτουριστικά της γυαλιά</a>, που σε πολλούς μπορεί να φαίνεται ακόμα μια πρωταπριλιάτικη πλάκα, αλλά το project είναι πέρα για πέρα αληθινό.</p>

<p>Αυτό όμως δεν σταματάει τον κόσμο στο Internet να σπάει πλάκα με τα sci-fi γυαλιά! Κάποιοι ισχυρίζονται ότι το προϊόν θα σου αποσπά πάρα πολύ την προσοχή και θα οδηγεί σε διάφορα ατυχήματα.</p>

<p>Ο <a href="http://tomscott.com" target="_blank">Tom Scott</a> δημιούργησε αυτή την παρωδία για τα Google Glasses, ονομάζοντας την “A New Way to Hurt Yourself.”<br> &nbsp;<br></p>
