<p>Η Microsoft δίνει δημόσια την πρώτη pre-release version του επόμενου λειτουργικού συστήματος της, των Windows 8. Τα Windows 8 Release Preview είναι διαθέσιμα για download από σήμερα. Η Release Preview έκδοση έχει κάποιες διαφορές από αυτήν που παρουσίασε η Microsoft νωρίτερα φέτος στο Mobile World Congress. Οι χρήστες τώρα μπορούν να πειραματιστούν με το νέο touch-friendly Metro UI και με μερικά Windows 8 applications όπως το Hotmail, το Messenger και το SkyDrive.</p>

<p>Ακολουθεί ένα video που ετοίμασε η εταιρεία για την κυκλοφορία της συγκεκριμένης έκδοσης. Περισσότερες πληροφορίες μπορείτε να βρείτε στην <a href="http://windows.microsoft.com/en-US/windows-8/release-preview" target="_blank">επίσημη ιστοσελίδα</a> των Windows 8 Release Preview.</p>
