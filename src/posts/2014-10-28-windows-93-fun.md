<p>Ποια είναι η αγαπημένη σου έκδοση των Windows; Τα Windows 8; Τα 7; Τα Vista; Τα 3.1; Σίγουρα μόλις μάθεις τα Windows 93 θα τα λατρέψεις. Τι κι αν δεν υπήρξαν ποτέ; Τουλάχιστον είναι διασκεδαστικά και έχουν πλάκα.</p>

<p>Το <a href=" http://kottke.org/14/10/windows-93" target="_blank">Kottke </a>ανακάλυψε μια ιστοσελίδα που παρουσιάζει μια φανταστική έκδοση των Windows. Είναι σαν τα Windows 95 να κυκλοφόρησαν το 1993. Πρόκειται ίσως για κάποια παρουσίαση της δουλειάς ενός designer. <a href="http://www.windows93.net/" target="_blank">Επισκεφθείτε την ιστοσελίδα</a> και κάνε κλικ στα διάφορα εικονίδια για να ανακαλύψεις τι κρύβουν.</p>
