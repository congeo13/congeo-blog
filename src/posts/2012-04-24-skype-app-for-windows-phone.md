<p>Το Skype <a href="http://blogs.skype.com/en/2012/04/skype_for_windows_phone_has_ar.html" target="_blank">βρίσκεται πλέον επίσημα στο κόσμο του Windows Phone</a>. Η εφαρμογή κυκλοφόρησε χθες στο Windows Phone Marketplace. Η εταιρεία επισήμανε ότι αυτή είναι &#8220;<em>μια από τις πολλές εκδόσεις που θα βγουν για το Windows Phone</em>&#8220;, θέλοντας να τονίσει ότι πιστεύει στις δυνατότητες της Windows Phone πλατφόρμας και ότι θα συνεχίσει να επενδύει στην εφαρμογή.</p>

<p>Η beta έκδοση του Skype για το Windows Phone είχε ανακοινωθεί στο Mobile World Congress τον Φεβρουάριο. Η εφαρμογή σου επιτρέπει να πραγματοποιείς voice και video calls σε 3G, 4G και Wi-Fi δίκτυα. Όπως γίνεται και στις άλλες εκδόσεις του προγράμματος, οι κλήσεις μπορούν να γίνουν δωρεάν στις Skype επαφές σου, ή σε σταθερά και κινητά με την χρήση των Skype credits. Με την εφαρμογή επιπλέον μπορείς να δημιουργήσεις ομαδικές συνομιλίες. Αξίζει να σημειωθεί ότι η εφαρμογή για Windows Phone είναι διαθέσιμη σε 18 γλώσσες.</p>

<p>Το Skype θα δουλεύει σε όλα τα Windows Phones που τρέχουν την έκδοση 7.5 Mango ή οποιαδήποτε νεότερη. Η εταιρεία δοκίμασε και πιστοποίησε την εφαρμογή στις ακόλουθες συσκευές: Nokia Lumia 710, Nokia Lumia 800, Nokia Lumia 900, HTC Titan, HTC Radar, Samsung Focus S και Samsung Focus Flash.</p>
