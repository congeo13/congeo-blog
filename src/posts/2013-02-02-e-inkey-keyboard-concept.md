<p>Το <a href="http://www.behance.net/gallery/E-inkey-(concept)/6878883" target="_blank">E-Inkey</a> πρόκειται ένα keyboard concept που θα μπορούσε να αποτελέσει το πρότυπο για τα keyboards της επόμενης γενιάς. Κάθε πλήκτρο του είναι μια μικρή E-ink οθόνη, πράγμα που σημαίνει ότι μπορεί να αλλάζει το εικονίδιο που βλέπεις πάνω του. Αν για παράδειγμα δουλεύεις στο Photoshop, τα πλήκτρα θα μπορούσαν να αλλάξουν σε Photoshop shortcuts για να σε βοηθήσουν ώστε να εκτελέσεις πιο εύκολα συγκεκριμένες ενέργειες. Και αυτό μπορεί να βρει εφαρμογή σε οποιοδήποτε άλλο πρόγραμμα επίσης.</p>

<p>Η ιδέα είναι τόσο έξυπνη και ταυτόχρονα απλή. Ας ελπίσουμε ότι σύντομα θα βρεθεί κάποιος να υλοποιήσει αυτή την ιδέα.</p>
