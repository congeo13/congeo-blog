<p>Η Microsoft <a href="http://windowsteamblog.com/windows/b/bloggingwindows/archive/2012/07/02/upgrade-to-windows-8-pro-for-39-99.aspx" target="_blank">μόλις ανακοίνωσε</a> μέσα από το επίσημο της blog, ότι το upgrade για τα Windows 8 Pro (διαθέσιμο για χρήστες που τρέχουν Windows XP, Vista ή 7) θα κοστίζει μόλις $40. Αυτό τα καθιστά τα φθηνότερα Windows που έχουν κυκλοφορήσει μέχρι στιγμής. Αυτή η τιμή ισχύει για αναβαθμίσεις που θα γίνονται από το Windows.com και ένας από τους λόγους που η εταιρεία ρίχνει τόσο πολύ την τιμή είναι γιατί η Microsoft στοχεύει στο να πουλήσει περισσότερα upgrades. Αν όμως κάποιος αγοράσει ένα upgrade DVD από κάποιο κατάστημα, αυτό θα κοστίζει $70.</p>

<p>Πρόκειται για μια δραματική μείωση της τιμής των Windows. Συνήθως οι εκδόσεις “Pro” κοστίζουν κοντά στα $200, με τις αναβαθμίσεις να πλησιάζουν τα $100. Η Microsoft αποκαλύπτει ότι έχει ορίσει αυτή την τιμή για σκοπούς προώθησης, η οποία θα κρατήσει μέχρι τις 31 Ιανουαρίου 2013. Να σημειωθεί επίσης ότι τα Windows 8 Pro δεν συμπεριλαμβάνουν το Windows Media Center, αλλά το πακέτο Media Center θα προσφέρεται σαν δωρεάν download μέχρι την προκαθορισμένη ημερομηνία.</p>
