<p>Η <a href="http://congeo.gr/tag/google">Google</a> πάντα μας εκπλήσσει με τις πρωτοπόρες ιδέες της και κάποιες φορές μοιάζουν σαν να είναι βγαλμένες μέσα από το μέλλον. Τελευταία υπήρξε μια φήμη για ένα project που αφορούσε μια συσκευή που θα μετέφερε την δύναμη του internet σ’ ένα ζευγάρι γυαλιά. Το όνομα αυτής, <a href="g.co/projectglass" target="_blank">Project Glass</a>.</p>

<p>Πρόκειται για ένα καταπληκτικό concept. Με μια συσκευή θα μπορέσουμε να κάνουμε πράγματα που ίσως να χρειαζόμασταν ακόμη και δύο συσκευές για να τα κάνουμε, όπως ένα smartphone και ένα tablet για παράδειγμα. Αυτά τα γυαλιά θα εξυπηρετούν πολλές ανάγκες, χωρίς να χρειάζεται να βγάζεις καν το κινητό σου από την τσέπη.</p>

<p>Υπάρχει όμως κάτι που σκέφτομαι. Όσο καταπληκτική κι αν είναι αυτή η ιδέα (αν βγει τελικά στην αγορά), θα μπορείς να επιλέγεις σε τι στυλ τα θέλεις ή θα βγαίνουν σε καθορισμένο σχέδιο; Γιατί μπορεί να μην σου ταιριάζουν στην τελική! Κι αν έχεις μυωπία; Θα μπορούν να τοποθετηθούν φακοί ή θα απευθύνονται μόνο σ’ αυτούς που δεν πρόβλημα με την όραση τους;</p>

<p>Βέβαια όλα αυτά μικρή σημασία έχουν αφού ακόμη δεν γνωρίζουμε αν το προϊόν θα βγει ποτέ στην αγορά. Φήμες που κυκλοφορούν πάντως, λένε ότι ίσως και να δούμε τη συσκευή αυτή στην αγορά, προς το τέλος της χρονιάς.</p>

<p>Το μέλλον είναι εδώ! Και δείτε πως το οραματίζεται η Google στο βιντεάκι που ακολουθεί.</p>
