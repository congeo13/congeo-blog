<p>Η Microsoft κυκλοφόρησε το πρώτο της Fitness Band με την ονομασία <a target="_blank" href="http://www.microsoft.com/microsoft-band/en-us">Microsoft Band</a>. Πρόκειται για μια συσκευή που γνωρίζαμε εδώ και λίγο καιρό για την κυκλοφορία της, αλλά σήμερα παρουσιάστηκε και επίσημα στην ιστοσελίδα της. Επίσης η εταιρεία κυκλοφόρησε και την εφαρμογή Microsoft Health η οποία θα αποθηκεύει τα δεδομένα που συλλέγονται από το Microsoft Band και θα δίνει συμβουλές στους χρήστες.</p>

<p>Όλα όσα γνωρίζουμε μέχρι στιγμής για τη συσκευή:<span></span></p>

<p><b>1. </b> Θα κοστίζει $199 δολάρια και θα κυκλοφορήσει σε 3 μεγέθη.</p>

<p><b>2. </b> Ζυγίζει σχεδόν 60 γραμμάρια.</p>

<p><b>3. </b> Διαθέτει έγχρωμη οθόνη.</p>

<p><b>4. </b> Συγχρονίζεται με λειτουργικά συστήματα Windows, OS X ή με το κινητό σου.</p>

<p><b>5. </b> Είναι συμβατό με Windows Phone 8.1, Android 4.3/4.4, iOS 7 και 8.</p>

<p><b>6. </b> Μπορεί να δέχεται φωνητικές εντολές αλλά μόνο με χρήση Windows Phone.</p>

<p><b>7. </b> Έχει ενσωματωμένο GPS για εντοπισμό αποστάσεων και UV sensor για μετρήσεις πραγματικού χρόνου της έκθεση του ήλιου.</p>

<p><b>8. </b> Είναι ανθεκτικό στον ιδρώτα, αλλά δεν είναι αδιάβροχο.</p>

<p><b>9. </b> Μπορεί να ανιχνεύει καρδιακούς παλμούς, βήματα, θερμίδες που καίγονται και τα μοτίβα του ύπνου σου.</p>

<p><b>10.</b> Η συσκευή μπορεί να εμφανίζει ειδοποιήσεις από το κινητό σου για emails, υπενθυμίσεις ημερολογίου, εισερχόμενες κλήσεις, μηνύματα, Facebook, Twitter και τον καιρό ή τις μετοχές.</p>

<p><b>11.</b> Θα μπορεί να πραγματοποιεί πληρωμές στα Starbucks και θα έρχεται με δώρο μια κάρτα αγορών αξίας $5 δολαρίων.</p>

<p><b>12.</b> Ακόμη δεν έχει γίνει γνωστό πότε θα είναι διαθέσιμο εκτός ΗΠΑ.</p>
